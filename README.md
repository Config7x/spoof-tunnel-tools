# spoof-egress-check

تست «باز بودن» دیتاسنتر برای جعل Source IP (اسپوف تانل)

برای اینکه بفهمید یک سرور ایرانی اجازه می‌دهد پکت با Source-IP جعلی (برای spoof-tunnel) بیرون برود یا نه.

## استفاده — فقط دو دستور

**۱. روی سرور خارجی** (گوش می‌دهد و در پایان نتیجه نهایی را چاپ می‌کند):
```bash
bash <(curl -sL https://raw.githubusercontent.com/Config7x/spoof-tunnel-tools/main/spoof-egress-check.sh) --listen
```

**۲. روی سرور ایرانی** (پکت‌های تست را می‌فرستد):
```bash
bash <(curl -sL https://raw.githubusercontent.com/Config7x/spoof-tunnel-tools/main/spoof-egress-check.sh) --target IP-سرور-خارجی
```

بعد از پایان حالت ۲، ترمینال سرور خارجی نتیجه هر سه پروتکل را با ✅/❌ چاپ می‌کند.

## گزینه‌ها
| گزینه | توضیح |
|---|---|
| `--spoof a,b,c` | لیست IPهای جعلی (پیش‌فرض `1.1.1.1,8.8.8.8,9.9.9.9`) — هر دو طرف یکسان |
| `--dur <ثانیه>` | مدت گوش دادن حالت `--listen` (پیش‌فرض 60؛ با اتمام تست ایران زودتر تمام می‌شود) |
| `--ssh root@IP` | حالت خودکار: روی ایران اجرا کنید، tcpdump خارج هم خودکار اجرا می‌شود (نیازمند کلید SSH) |

## پروتکل‌های تست‌شده
- **ICMP** — پایه‌ای‌ترین تست (پینگ)
- **UDP/DNS** — شبیه ترافیک DNS
- **TCP SYN** — حالت سخت‌تر

## تفسیر نتیجه
- **ICMP باز + UDP باز** → دیتاسنتر فیلتر خروجی ندارد؛ برای اسپوف تانل قابل استفاده است
- **فقط ICMP باز** → فقط همان حالت کار می‌کند
- **همه بسته** → BCP38 فعال است؛ سراغ ارائه‌دهنده دیگر بروید
- اگر همه بسته بود، با `--spoof` یک IP از همان رنج سرور ایرانی هم تست کنید (بعضی دیتاسنترها فقط رنج خودشان را می‌گذارند بیرون)

## نکته مهم
ایران به ایران معمولا باز است؛ چیزی که باید تست کنید **ایران به خارج** است، چون Source-IP جعلی باید از لیست سفید خروج بین‌المللی عبور کند. برای پیدا کردن IPهای وایت‌لیست از ماژول tester پنل [spoof-tunnel](https://github.com/ParsaKSH/spoof-tunnel) استفاده کنید.
